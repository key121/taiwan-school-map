# 全台學區地圖｜輸入地址查國中小學區

線上版：https://key121.github.io/taiwan-school-map/

輸入地址，或選「鄉鎮市區 → 村里 → 鄰」，即可查詢國小、國中學區。支援步行距離與時間、學校反查學區範圍、分享連結、手機版。純靜態網站，沒有後端，不蒐集個資。

- `index.html`：全國版主地圖（22 縣市，各縣市資料按需載入）
- `coverage.html`：各縣市收錄狀態總覽
- `keelung/`：基隆專版，以門牌精確比對里鄰

各縣市的官方連結請見 `coverage.html` 或 `data/registry.json`。

## 資料來源

- **學區**：各縣市政府教育局（處）公告的學區劃分表，學年度如上表。
- **村里界**：內政部國土測繪中心 村(里)界（TWD97 經緯度），1150817 版。
- **鄰數**：內政部戶政司 村里鄰戶數，115 年 7 月。
- **學校名錄**：教育部統計處 115 學年度國民小學／國民中學名錄。
- **學校座標**：OpenStreetMap（ODbL），少數以 ArcGIS 地址定位補足。
- **底圖**：© OpenStreetMap 貢獻者。
- **步行路線**：OSRM（FOSSGIS）。
- **地址定位**：ArcGIS World Geocoder，在使用者瀏覽器中即時查詢，結果不儲存。

## 免責聲明

本站整理政府公開資料，提供民眾查詢便利，並非政府官方網站。學區依戶籍地址的里、鄰認定，並受設籍期限、總量管制、額滿分發、共同（自由）學區等規定影響。實際入學請以學校及各縣市教育局（處）公告為準。

線上地址定位僅供參考，落點靠近里界時可能誤判，請以戶口名簿上的里鄰為準。新北市、新竹市、嘉義市的學區資料由程式解析而成，每筆結果都附官方原文，若兩者不一致，以原文為準。
